# Conditions d'utilisation du contenu

Ce repo contient les dictées téléchargées par l'application Android Dictée :
textes, enregistrements audio, illustrations et catalogue. Il est public parce
qu'il est servi par un CDN gratuit (jsDelivr) et par GitHub Pages. **Public ne
veut pas dire libre de droits.**

## 1. Usage autorisé

Le contenu est destiné à être téléchargé et utilisé **par l'application
Dictée**, pour un usage personnel d'entraînement à l'orthographe.

Il est également permis de consulter ce repo, et de signaler une erreur dans
une dictée (faute, coupure audio, mauvaise annotation) en ouvrant une issue.

Sauf autorisation écrite préalable de l'éditeur de l'application, il est
interdit :

- de copier, redistribuer, republier ou revendre tout ou partie du contenu,
  que ce soit sous forme de fichiers, de site, d'application ou de document ;
- d'utiliser le contenu dans une autre application ou un autre service,
  gratuit ou payant ;
- d'aspirer le contenu de manière automatisée, ou de l'utiliser pour entraîner
  ou évaluer un modèle d'intelligence artificielle ;
- d'accéder aux dictées réservées au Pass de l'application en contournant
  l'application.

  une issue ou contactez l'éditeur via la fiche Play Store de l'application :
